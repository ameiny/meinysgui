# Meinys GUI

Small quality-of-life tweaks for Minecraft's inventory screens.

## Features
- Sort containers and your inventory with one click
- Deposit all items, or only matching ones, into a container
- Take all items, or only matching ones, out of a container
- Hotkeys for every action (sort defaults to R)
- Settings for the hotbar and which buttons are shown

## Requirements
- [Fabric Loader](https://fabricmc.net/use/)
- [Fabric API](https://modrinth.com/mod/fabric-api)
- [Mod Menu](https://modrinth.com/mod/modmenu) (optional)

## Server
Works on any server, including vanilla. Installing the mod on the server
as well makes sorting faster and more reliable, but it's optional.
